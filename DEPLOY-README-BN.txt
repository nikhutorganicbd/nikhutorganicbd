নিখুঁত অর্গানিক বিডি — SEO আপডেট প্যাকেজ (পরীক্ষার কপি)

এই ZIP-এর ফাইলগুলো ওয়েবসাইটের ROOT ফোল্ডারে একই কাঠামো বজায় রেখে আপলোড করবেন:
- index.html
- robots.txt
- sitemap.xml
- og-cover.webp
- assets/ (ভেতরের সব WebP ছবি)

সতর্কতা:
1) পুরোনো সাইটের ব্যাকআপ আগে রাখুন।
2) ZIP extract করে ফাইলগুলোর folder structure ঠিক রাখুন।
3) প্রথমে preview/staging-এ পরীক্ষা করুন; সব ঠিক থাকলে live root-এ deploy করুন।
4) Deploy-এর পর https://nikhutorganicbd.com/robots.txt এবং /sitemap.xml খুলে দেখুন।
5) Search Console → URL Inspection-এ homepage পরীক্ষা করে Request Indexing দিন।
6) Sitemap আগে থেকেই Success দেখালে সেটি আবার জমা দেওয়া বাধ্যতামূলক নয়; deploy-এর পর status পর্যবেক্ষণ করুন।

যা করা হয়েছে:
- Title, meta description, canonical, robots meta
- Open Graph এবং Twitter Card
- Organization/OnlineStore ও WebSite JSON-LD
- HTML থেকে embedded base64 ছবিগুলো আলাদা WebP asset করা হয়েছে, যাতে browser cache করতে পারে
- robots.txt এবং sitemap.xml যুক্ত

যা এখনো যাচাই/অনুমোদন দরকার:
- সাইটে দেখানো হেড অফিস/আউটলেট ঠিকানা বাস্তবে ক্রেতা-সামনাসামনি সেবা দেয় কি না
- প্রতিটি ব্যাচ পরীক্ষিত, রিটার্ন সুবিধা, ১০০% খাঁটি/ভেজালমুক্ত—এই দাবিগুলোর প্রমাণ ও নীতিমালা
- পেমেন্ট নম্বর ও প্রতিটি পণ্যের বর্তমান দাম/ওজন
- মোবাইল/ডেস্কটপে লাইভ checkout ও WhatsApp order পরীক্ষা

নোট: Google ranking বা indexing নিশ্চিত করা যায় না। এই সাইটে বর্তমানে একটি মূল HTML URL আছে; #products/#offer ইত্যাদি অংশ আলাদা Google-indexable page নয়।
